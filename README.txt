MANNVASAM RECIPE STUDIO UPGRADE
================================

Included:
- recipes.html
- recipes.js
- recipes-data.js
- recipes.css

Recipe collection: 33 recipes
- 19 Indian Vegetarian (including Tamil Nadu traditional dishes)
- 6 Indian Non-Vegetarian
- 8 World Recipes

Features:
- Category filters and recipe search
- Serving scaler (1–20 people)
- Interactive cooking-pot ingredient game (2D animated, touch-friendly)
- Ingredient quantities scaled from a 2-serving base
- Cooking-step checklist and progress
- Favorites stored in browser localStorage
- Shopping-list panel
- Reduced-motion accessibility

Install into the local Vite project:
1. Make a backup of the existing four files.
2. Copy these four files into the project root, replacing the existing files.
3. Run `npm run build`.
4. Start the local Vite dev server and open `/recipes.html`.

No deployment is performed.

Notes:
- Recipe quantities are practical starting quantities and may need adjustment for rice variety, cookware, appetite, and local taste.
- This is an animated 2D cooking interaction, not a full 3D physics simulation.
- The library is expandable; 33 recipes are an initial broad collection, not literally every recipe in the world.
